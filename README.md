# funny-lexer

Учебный проект по дисциплине ТВПОЯ: реализация
лексера, парсера и семантического анализатора для языка
программирования **Funny**.

## Что внутри

Проект разбит на этапы трансляции:

| Этап | Пакет | Что делает |
|------|-------|------------|
| Лексический анализ | `internal/lexer`, `internal/nfa`, `internal/dfa`, `internal/runner` | Построение NFA/DFA по спецификации токенов, минимизация (Хопкрофт), прогон входной строки |
| Синтаксический анализ | `internal/parser`, `internal/ast` | Рекурсивный спуск, построение AST |
| Семантический анализ | `internal/semantic` | Таблица символов, проверка типов, вывод типов, диагностика ошибок |

Описание языка и заданий — в `docs/hw2.md` и `docs/hw3.md`.
